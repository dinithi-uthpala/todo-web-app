# Todo Web App

A split repo Todo application with a modern Next.js frontend and a Laravel backend API. The app supports user registration, login, and authenticated task management with create/read/update/delete Todo functionality.

## Features

- User authentication (register, login)
- Protected dashboard with task list
- Create, edit, delete Todos
- Search and filter task list
- Modern responsive UI with Tailwind CSS
- Local illustrations and consistent theme

## Repository structure

- `backend/` — Laravel application, API and auth backend
- `frontend/` — Next.js app, UI layer and API client

## Tech stack

- Frontend
  - Next.js 16
  - React 19
  - TypeScript
  - Tailwind CSS 4
- Backend
  - Laravel
  - Vite
  - PHP
